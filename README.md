# 🎵 Task 19 – Music Player UI

A modern, responsive music player interface developed as part of the **Veda Technology Graphic Design / Web Development Internship Task 19**.

The project uses **HTML5, CSS3, and JavaScript** with the **HTML5 Audio API** to provide a functional music playback experience.

## 🔗 Live Demo

https://silambarasanc199-jpg.github.io/task-19-music-player/

---

## 📌 Project Overview

**Vibe** is a responsive web-based music player designed with a clean, modern, and futuristic interface.

The application allows users to select songs from a playlist, control playback, adjust volume, seek through tracks, and automatically move to the next track when a song ends.

---

## 🎯 Objective

The main objective of this task is to understand and implement:

- HTML5 Audio API
- JavaScript event listeners
- Audio playback controls
- Real-time progress tracking
- Playlist interaction
- Volume management
- Responsive UI design

---

## ✨ Features

- ▶️ Play / Pause music
- ⏮ Previous track
- ⏭ Next track
- 🎵 Interactive playlist
- 📊 Live playback progress
- ⏱️ Current time and duration display
- 👆 Click / drag to seek through a song
- 🔊 Volume control
- 🔇 Mute / Unmute
- 🔄 Automatic next-track playback
- 📱 Responsive mobile-friendly interface
- 🎨 Modern dark music-player design
- ⚡ No external JavaScript framework required

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**
- **HTML5 Audio API**
